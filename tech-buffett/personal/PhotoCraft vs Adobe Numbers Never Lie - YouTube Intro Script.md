## Production notes

- **Alternate cold open (more provocative):** "One developer says, quote, 'software is over.' To prove it, he rebuilt Photoshop in three weeks and gave it away." Use this if the thumbnail already shows **35 YEARS vs 3 WEEKS**, so the opener doesn't repeat the thumbnail.
- **Alternate twist line (for a more bearish-on-Adobe audience):** "PhotoCraft can't replace Photoshop today. But it took three weeks to get this far. What does it look like in a year?"
- **Fact-check:**
  - Photoshop 1.0 shipped in **1990**, so "more than thirty-five years" is safe.
  - First commit **Sept 30, 2026**. The Adobe-app suite launched **~Oct 7**. "Three weeks" holds through roughly Oct 21; say "about a month" if you record later.
  - "Seven Adobe apps": Photoshop, Lightroom, Premiere Pro, Illustrator, After Effects, InDesign, Acrobat. The Office clones came later; don't count them here.
  - "Most of the code was written by AI": multiple outlets report parallel Claude Opus 5.5 agents, and Opus is listed as a co-author in the git history. Thomas calls it "agentic coding."
  - Cancellation-fee quote: Thomas, via Glyn Dewis: "They charged me the 'cancellation fee' on multiple occasions."
  - HSBC, Oct 13, 2026: Buy → Hold, target $310 → $267, citing AI-built clones. Recent reports put the stock around ~$238.
  - The "not ready for professionals" line paraphrases the README: "not yet a Photoshop replacement for daily professional work."
- **"Wall Street noticed"** is slightly generous. The stock barely moved on the downgrade itself, because it was already down ~30% this year. The body of the video (Slide 26) says this explicitly. Don't imply PhotoCraft caused the selloff.
- **Funnel graphic:** the intro uses the general Adobe vs. Gen AI version, because the line is about AI broadly. Use the PhotoCraft version later in the video, in the "Will pros switch?" section.
